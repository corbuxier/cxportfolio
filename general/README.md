# 通用 AI 产品经理作品集

这是区别于 B站定向版本的通用投递网站，适合投递其他公司的 AI 产品岗。

打开方式：

```powershell
start D:\Claude\bilibili\portfolio-general\index.html
```

站点使用三个既有项目：

- 内容平台 AIGC 趋势与创作者 AI 工具分析
- FitMirror 智能健身助手
- 东游记 AI 旅行 Story Teller

详情页：

- `content-ai.html`
- `fitmirror.html`
- `dongyouji.html`

注意：这里没有复制 FitMirror 的 155MB 原视频，使用的是 GitHub Pages 版本中约 49MB 的压缩视频。内容项目短视频约 6.7MB。
